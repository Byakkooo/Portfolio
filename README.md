## Projets présentés

### Menu Maker by Qwenta

Projet consacré à la préparation et à la planification d'une application permettant aux restaurateurs de créer et personnaliser leurs menus.

Compétences mises en œuvre :

- Rédaction de spécifications techniques
- Planification Agile
- Organisation d'un Kanban
- Veille technologique
- Analyse des besoins

### ArgentBank

Application bancaire développée avec React et connectée à une API REST.

Compétences mises en œuvre :

- Développement React
- Gestion d'état
- Authentification utilisateur
- Routes protégées
- Communication avec une API REST
- Gestion des données utilisateur
