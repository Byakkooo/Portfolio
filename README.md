## Installation

Cloner le projet :

```bash
git clone https://github.com/Byakkooo/Portfolio.git
cd Portfolio
```

Installer les dépendances :

```bash
npm install
```

Lancer le serveur de développement (puis ouvrir http://localhost:5173) :

```bash
npm run dev
```

> Le projet utilise React et Vite : ouvrir `index.html` directement dans le navigateur ne fonctionne pas, il faut passer par `npm run dev`.

## Déploiement

Le site est publié sur GitHub Pages depuis la branche `gh-pages` :

```bash
npm run build
```

Le contenu du dossier `dist/` est ensuite publié sur la branche `gh-pages`.
